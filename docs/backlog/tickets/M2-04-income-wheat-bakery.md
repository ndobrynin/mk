# M2-04 — доход старта

## Зачем

Первые две карты: синее поле на 1 в любой ход, зелёная пекарня на 2–3 только в свой.

## Скоуп

После roll, фаза income:

- выпало **1**: каждый игрок с wheat-field получает +1 из банка за каждую копию (старт: по одной)
- выпало **2** или **3**: только **активный** получает +1 за bakery
- иначе монеты не меняются от этих карт
- затем фаза `build`

Тесты с rng, дающим 0 → кубик 1; дающим 1 → кубик 2.

Не делать красные, Торговый центр, остальные карты.

## Контекст

- `docs/rules.md` §2 цвета, §8 синие/зелёные: Пшеничное поле, Пекарня
- `packages/engine/CONTRACT.md`

## Критерии приёмки

- [ ] Кубик 1: оба игрока +1 (было 3, стало 4)
- [ ] Кубик 2: активный +1, соперник 3
- [ ] Кубик 4 (rng 3): оба остаются на 3
