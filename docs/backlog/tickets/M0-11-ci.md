# M0-11 — CI как второй tester

## Зачем

Агентский PASS без пайплайна нельзя проверить на GitHub. Минимальный workflow гоняет тесты пакетов.

## Скоуп

`.github/workflows/test.yml`:

- on push/PR в `main`
- Node 20, pnpm
- `pnpm install --frozen-lockfile`
- `pnpm --filter @kidagrad/engine test`
- `pnpm --filter @kidagrad/api test` (если пакет уже есть)
- `pnpm --filter @kidagrad/web build`

Без сервисов Postgres в CI в этом тикете: api-тесты health без БД должны проходить. Не поднимать Docker-in-Docker.

Не делать deploy, lint-only job, coverage gates.

## Контекст

- `docs/backlog/README.md` (CI как второй tester)
- существующие `package.json` фильтров
