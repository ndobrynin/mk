# Локальная среда и порты

Спека для Docker и портов Кидаграда. Её обязаны соблюдать `docker-compose`, `.env.example` и дальнейшая разработка: не перетирать чужие контейнеры и не садиться на занятые порты.

Снимок хоста на 17.08.2026. Если добавятся новые контейнеры — обновить эту таблицу, а не сдвигать порты Кидаграда без нужды.

## Занято на машине (не трогать)

Чужие контейнеры **Up**:

| Контейнер | Образ | Хост → контейнер |
| --- | --- | --- |
| `admin-service-db` | postgres:15-alpine | **5432** → 5432 |
| `store-medusa-db` | postgres:17-alpine | **5433** → 5432 |
| `blog-translate-check-db` | postgres:15.4 | **5434** → 5432 |
| `store-redis` | redis:7-alpine | **6379** → 6379 |

Остановленные контейнеры, которые снова займут те же порты, если их поднять:

| Контейнер | Конфликт |
| --- | --- |
| `trade_bot_db` | 5433 |
| `strapi_database` | 5432 |
| `pullradar-redis` | 6379 |

Другие слушатели хоста (не Docker, но не занимать): `5000` / `7000` (AirPlay / Control Center), `1337` (node), `6881` (uTorrent).

**Нельзя:**

- публиковать Кидаград на `5432`, `5433`, `5434`, `6379`;
- подключаться к чужим инстансам Postgres/Redis «чтобы не поднимать свои»;
- называть контейнеры `postgres`, `redis`, `db` без префикса — только `kidagrad-*`;
- использовать compose-проект с именем, которое пересекается с чужими (`admin-service`, `store`, `blog-translate`, `pullradar`, `trade_bot`).

## Порты Кидаграда (зарезервированы)

Отдельные контейнеры, отдельные тома, отдельные имена.

| Сервис | Имя контейнера | Хост | Внутри контейнера | Том |
| --- | --- | --- | --- | --- |
| PostgreSQL 16 | `kidagrad-postgres` | **5435** | 5432 | `kidagrad_pgdata` |
| Redis 7 | `kidagrad-redis` | **6380** | 6379 | `kidagrad_redis` |
| Nest API | процесс / сервис `kidagrad-api` | **4010** | 4010 | — |
| Vite / React | процесс `kidagrad-web` | **5173** | 5173 | — |

Compose-проект: **`kidagrad`**.

База: имя `kidagrad`, пользователь `kidagrad`, пароль только из env (`KIDAGRAD_POSTGRES_PASSWORD`). Не `postgres`/`postgres`.

Примеры URL:

```
DATABASE_URL=postgresql://kidagrad:…@127.0.0.1:5435/kidagrad
REDIS_URL=redis://127.0.0.1:6380
PORT=4010
VITE_API_URL=http://127.0.0.1:4010
```

Фронт на `http://127.0.0.1:5173`.

## Docker Compose (когда появится)

Файл — `infra/docker-compose.yml` (или корень с `name: kidagrad`). Обязательные поля:

```yaml
name: kidagrad
services:
  postgres:
    container_name: kidagrad-postgres
    ports:
      - "5435:5432"
  redis:
    container_name: kidagrad-redis
    ports:
      - "6380:6379"
```

Проверка перед `up`: `lsof -nP -iTCP:5435,6380,4010,5173 -sTCP:LISTEN` — должно быть пусто, либо это уже Кидаград.

Если порт внезапно занят — **не** откатываться на `5432`/`6379`. Взять следующий свободный в том же ряду (`5436`, `6381`) и сразу поправить эту спеку и `.env.example`.

## Зачем не 3000 у API

Nest по умолчанию слушает `3000`. На этой машине порт сейчас свободен, но его часто занимают чужие фронты и контейнеры. API Кидаграда всегда `4010`, чтобы не пересечься с типичным React/`next start`.
